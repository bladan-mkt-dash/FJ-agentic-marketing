How SEO Sally gets her KPI data

Six tools feed one Postgres database on a fixed schedule, and SEO Sally reads from there with read-only access to run the KPI dashboard, the monthly scorecard and her recommendations for Five Journeys. The KPIs themselves are on the SEO Sally job page.

The full picture

Five Journeys’ Cursor agent pulls from each tool on its own schedule and saves dated snapshots in Drawer A. SEO Sally never touches the tools or their API keys; she only reads the tables.

Our AI Visibility score

Score = 0.5 × min(100, AI Overviews ÷ 21 × 100) + 0.3 × min(100, AI Mode ÷ 38 × 100) + 0.2 × min(100, ChatGPT ÷ 10 × 100)

Each platform scores 0–100 against its Dec 2027 target, and the weights (50% AI Overviews, 30% AI Mode, 20% ChatGPT) follow how many searchers each reaches; Bruno can change them. 100 means every target is hit. Baseline is about 38 (Jun–Sep 2026 average), Sep 2026 is 19.4, and the target is 100 by Dec 2027. It is backfilled from the Ahrefs citation counts in Drawer A from Apr 2026, the first month with AI Mode data, and shown next to GA4 AI referral sessions from chatgpt.com, perplexity.ai, gemini and copilot.

Calculated monthly from the three Ahrefs AI citation counts, so it needs no extra tool or API calls.

Why reading from Postgres beats going into each tool

Benefits

  • One place for every metric, with consistent definitions
  • Dated history builds up, and nothing is overwritten
  • API keys stay with Bruno; SEO Sally’s access is read-only, so nothing can be changed
  • Lower usage: small structured queries instead of long raw API responses
  • API units are spent once per scheduled pull and tracked in sync_runs, so a nearing plan cap is visible
  • Data is ready on a fixed schedule, before reporting
  • Tools can be swapped without changing the dashboard logic: dropping Semrush only meant removing its pull and mapping its KPIs to Ahrefs, Search Console and BrightLocal

Caveats

  • Data is only as fresh as the last pull
  • An AI-run dump uses some Cursor usage; a plain scheduled script uses none
  • Each tool’s plan caps still need checking
